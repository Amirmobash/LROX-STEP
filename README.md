# LROX-STEP – Sensor STEP File Library

A collection of **3D CAD STEP files for sensor-related projects**, mechanical design, enclosure development, mounting systems, prototyping, and engineering integration.

This repository was created to provide useful sensor models that can be imported into common CAD software and used during the design of machines, automation systems, smart-home projects, electronic enclosures, and custom mounting solutions.

## Repository

* [LROX-STEP GitHub Repository](https://github.com/Amirmobash/LROX-STEP)

```bash
git clone https://github.com/Amirmobash/LROX-STEP.git
```

---

## Overview

The repository contains STEP files for sensors and related components.

These files can help engineers, designers, makers, and developers to:

* Design custom sensor holders
* Create protective enclosures
* Develop mounting brackets
* Check available installation space
* Integrate sensors into machines
* Prepare automation layouts
* Build smart-home and IoT projects
* Create technical prototypes
* Reduce repeated measurement and modeling work

The models are intended primarily as mechanical reference files for CAD design.

---

## File Format

The models are provided in the **STEP** format.

STEP files are suitable for use in many professional and hobby CAD applications, including:

* SolidWorks
* Autodesk Fusion
* FreeCAD
* Siemens NX
* PTC Creo
* CATIA
* Inventor
* Onshape
* Solid Edge
* Other STEP-compatible CAD software

## Recommended Workflow

1. Download or clone the repository.
2. Select the required sensor STEP file.
3. Import the file into your CAD software.
4. Check the dimensions against the physical sensor.
5. Position the model inside your assembly.
6. Design the required holder, enclosure, bracket, or machine component.
7. Test the final design before manufacturing.

---

## Important Notes

* The files are provided as mechanical reference models.
* No physical sensors or electronic components are included.
* Always verify the dimensions with the original sensor before manufacturing.
* Small dimensional differences may exist between product revisions.
* Connector positions, cable clearances, and mounting tolerances should be checked manually.
* The models should not be used as the only source for safety-critical applications.
* The repository may be updated with additional sensor files over time.

---

## Accuracy and Tolerances

The STEP files are intended to support design and prototyping work.

Before creating a final part, please verify:

* Overall sensor dimensions
* Mounting hole positions
* Connector locations
* Cable routing space
* Required installation clearance
* Sensor orientation
* Mechanical tolerances
* Access for maintenance and replacement

For 3D-printed holders or enclosures, an additional tolerance should be included depending on the printer, material, and required fit.
